# 🎯 Quick-Pointer

**Quick-Pointer** is a fast-paced browser game that challenges your reflexes, precision, and speed. Your objective is simple: click the moving target as many times as possible before the timer reaches zero.

---

## 📖 About

Quick-Pointer is a lightweight shooting game built using **HTML**, **CSS**, and **JavaScript**. It was created to practice DOM manipulation, event handling, animations, timers, and game logic while providing a fun experience.

---

## 🚀 Features

- 🎯 Moving target
- ⏱️ Countdown timer
- 🏆 Live score tracking
- 🖱️ Mouse-click gameplay
- ⚡ Fast-paced challenge
- 📱 Responsive design
- 🔄 Restart game anytime

---

## 🎮 How to Play

1. Click **Start Game**.
2. The target will appear at random positions.
3. Click the target before it moves again.
4. Each successful hit increases your score.
5. Keep playing until the timer reaches **0**.
6. Try to beat your highest score!
